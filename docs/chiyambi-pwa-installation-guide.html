Installation and offline-use guide

Learn anywhere.
Keep going offline.

Step-by-step instructions for installing the Chiyambi Learning Platform on phones, tablets, Chromebooks, Windows computers and Macs—and using it when internet access is unavailable.

For families, teachers, schools and centres Progressive Web App (PWA) edition · Version 1.0 · 2026

Before you install

Complete these checks once while you have a stable internet connection.

Quick preparation
  • Connect the device to Wi-Fi or mobile data.
  • Open the official Chiyambi web address supplied by FISD.
  • Use an up-to-date browser. Chrome or Edge is recommended where available.
  • Allow enough storage for the app, learning pages and offline media.
  • Open Chiyambi at least once after installation so essential content can be saved.
Important: Chiyambi is a Progressive Web App. On Android it installs from the browser and behaves like an app; users should not download an APK from an unknown website or message.

2

Android phone or tablet

Recommended method: Google Chrome.

1

Open Chiyambi

In Chrome, enter the official Chiyambi web address and wait for the home page.

2

Choose Install

If Chiyambi shows an Install Chiyambi button, select it. Otherwise, open Chrome’s three-dot menu and choose Install app or Add to Home screen.

3

Confirm

Select Install. The Chiyambi icon will be added to the Home screen or app list.

4

Open the installed app online once

Launch Chiyambi from its new icon and allow the first page to finish loading.

5

Prepare lessons for offline use

While online, open the learning stage, lesson or resource you expect to use. Pages already visited are the most reliable when the connection is unavailable.

Samsung Internet: open the menu, choose Add page to, then select Home screen. Chrome remains the recommended option for the fullest PWA installation experience.

How to recognise the installed version

Chiyambi opens in its own window without the normal browser address bar. It also appears in the device’s app list and can be pinned to the Home screen.

3

iPhone or iPad

Use Safari. Other iOS browsers may not show the required Home Screen option.

1

Open Safari

Visit the official Chiyambi web address and wait for the home page to load fully.

2

Open the Share menu

Select Safari’s Share button—the square with an upward-pointing arrow.

3

Add to Home Screen

Scroll through the available actions and select Add to Home Screen.

4

Confirm the app name

Keep the name Chiyambi, then select Add.

5

Launch and prepare offline content

Open the new icon while online and visit the lessons or resources needed later.

If Add to Home Screen is missing, select Edit Actions at the bottom of the Share menu and add it to the list.

iPhone and iPad storage

iOS may remove cached website data when storage is very low or an app has not been used for a long period. Reconnect and open Chiyambi periodically to refresh offline content.

4

Windows and Chromebook

Install Chiyambi as a dedicated desktop application.

W

Microsoft Edge on Windows

  1. Open Chiyambi in Edge.
  2. Open the three-dot menu.
  3. Choose Apps.
  4. Select Install Chiyambi.
  5. Confirm installation.
  6. Choose whether to pin it to Start or the taskbar.
C

Google Chrome on Windows

  1. Open Chiyambi in Chrome.
  2. Select the install icon in the address bar, if shown.
  3. Or open the three-dot menu and choose Cast, save and share.
  4. Select Install page as app.
  5. Confirm with Install.
CB

Chromebook

  1. Open Chiyambi in Chrome.
  2. Select the install icon at the right of the address bar.
  3. Select Install.
  4. Open Chiyambi from the Chromebook Launcher.
PC

After installation

  1. Open the app while connected.
  2. Visit required learning areas.
  3. Pin Chiyambi for easy access.
  4. Do not clear browser site data unless offline files are no longer needed.
A desktop PWA uses the same secure Chiyambi account and content as the website. There is no separate Windows installer to download.
5

Mac installation

Use Safari, Chrome or Edge on a supported macOS version.

Safari on macOS Sonoma or later

1

Open Chiyambi in Safari.

2

From the menu bar, choose File → Add to Dock.

3

Confirm the name Chiyambi and select Add.

4

Open Chiyambi from the Dock or Applications folder while online once.

Chrome or Edge on Mac

1

Open Chiyambi and select the install icon in the address bar.

2

If no icon appears, use the browser menu and choose Install page as app or Apps → Install Chiyambi.

Confirm installation, open the app, and visit the content needed offline.

On an older macOS version without Safari’s Add to Dock, install through Chrome or Edge instead.

Using Chiyambi offline

The platform stores essential app files and queues supported activity on the device.

What happens automatically
Work or learn while offline
→
Activity is saved securely on the device
→
Saved activity syncs after reconnection

When the connection is lost

  • Chiyambi displays an offline notice and opens the offline page.
  • Select Go to home to continue with available cached content.
  • Previously loaded pages and core learning media remain available.
  • Supported activity is stored in the device’s offline queue.

When the connection returns

  • Keep Chiyambi open for a short time.
  • A message confirms that the connection has returned.
  • Saved activity is sent automatically; there is no manual upload step.
  • If items remain pending, leave the app open and confirm the connection is stable.
Best practice: before travelling to a low-connectivity area, open the app online and visit each lesson, story or resource that will be needed.

Content that may still require internet

Live classes, first-time account verification, new content that has never been opened, and external media may require a connection. Offline availability grows as content is opened and cached on the device.

7

Updates, troubleshooting and removal

Simple checks resolve most installation and offline-use problems.

Get the latest version

  1. Connect to the internet.
  2. Open Chiyambi and keep it open briefly.
  3. Close and reopen the app. If necessary, refresh the page once.

If Chiyambi will not install

Problem What to do
No Install option Use a supported browser, leave Private mode, reload, and browse the app briefly.
App opens as a normal tab Remove the shortcut and repeat the PWA installation steps for the device.
Offline page has limited content Reconnect and visit the required learning pages before going offline again.
Saved activity remains pending Check the connection, reopen Chiyambi, and leave it open while it synchronizes.
Storage warning Free device storage without clearing Chiyambi’s site data.

Remove the installed app

On a phone or tablet, press and hold the Chiyambi icon and choose Uninstall or Remove App. On a computer, open the app menu and choose Uninstall Chiyambi.

Removing the app or clearing browser site data may delete activity that is still waiting to synchronize. Connect and allow synchronization before removal.
